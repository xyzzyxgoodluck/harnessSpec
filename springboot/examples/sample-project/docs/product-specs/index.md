# product-specs —— 需求规格索引

> 本目录存放**需求/产品规格**（做什么 / 为什么 / 验收标准），每个需求一个文件，命名 `{{编号}}-{{简短名}}.md`。
> 固定组成部分：**目录必建**（含本文件与 `TEMPLATE.md`）；需求文件按触发器写入——首个需求/规格立项时复制 `TEMPLATE.md` 起草并在本表登记。
> 与 `ARCHITECTURE.md`（结构/边界）、`CODING_STANDARDS.md`（编码细则）、`AGENTS.md`（操作手册）分工不重复。
> 使用说明见仓库固定规范 `docs/fixed-docs.md` 与需求模板 `TEMPLATE.md`。

## 状态流转

`草稿 → 评审中 → 已确认 → 开发中 → 已完成 → 已废弃`

> 已确认内容**只增不改**；需求变更追加到该需求文件的「评审与变更记录」并重新评审。
